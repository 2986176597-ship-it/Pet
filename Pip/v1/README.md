# Pip v1

This is the first published version of Pip's ChatGPT Pet artwork.

- `Pip-spritesheet.png` is the exact 1536×2288 transparent atlas that passed the Pets plugin preflight and the local quality gate.
- `source/base.png` is the canonical character reference.
- `source/rows/` contains the editable source strips for all nine standard animation rows and both eight-pose look-direction rows.
- `source/references/approved-cardinal-anchors.png` contains the approved up, right, down, and left pose anchors.
- `previews/` contains the motion and direction previews.

The source strips preserve the original generated artboards. Edit or regenerate them as needed, then assemble and validate a new final atlas before updating the active ChatGPT Pet.
