# Pip

Pip is a calm, curious clay fox companion. The concept uses only what this conversation supports: the user works in Codex and chose an animated ChatGPT Pet; no appearance or unrelated interests were inferred.

## Current version

The current published version is [`v1`](v1/). It contains the final validated v2 atlas, original editable row strips, canonical base art, and motion/direction previews.

## Updating Pip

1. Start a branch from the current version and edit `v1/source/` or prepare a new set of source art.
2. Export the next final sheet as `v2/Pip-spritesheet.png` (1536×2288 PNG, RGBA, transparent background, 8 columns × 11 rows, 192×208 cells).
3. Keep the source art and previews with that new version, and run the ChatGPT Pets preflight before replacing Pip in Work.
4. Change the current-version link in this file to `v2/` and commit the version together.

The GitHub account that owns this repository has admin and push permission, so it can edit files, create branches, and publish future versions.
